# Devastator 2

Lunar trench defense with a pod-race heart. Sequel to
[Devastator](https://github.com/wells01440/devastator), the 1984
COMPUTE! game ported to macOS.

**Status: design settled, grey-box prototype next.** The gameplay spec
is [DESIGN.md](DESIGN.md).

macOS only. Swift + SpriteKit. Build with `swift build`, run with
`swift run` (macOS 13+, Xcode toolchain).

Soundtrack: owner-composed chiptune and demoscene tracks; see
[Assets/Music/MANIFEST.md](Assets/Music/MANIFEST.md).
