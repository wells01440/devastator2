# Devastator 2

The sequel to the Devastator port in ../devastator. Design phase: gameplay
is being worked out in DESIGN.md. No code yet, by decision.

Before writing FutureBasic code, read ../devastator/AGENTS.md; it holds the
build-system and language lessons from the port (line endings, reserved
words, key input, sound linking, IDE-driven builds).

The port's game: crosshair gunsight vs an evading saucer over a warp
corridor, 10-second doom clock, 1000 points saves the Earth. The sequel
reframes it as a lunar trench race defense; see DESIGN.md.
